What it is — and isn’t

What it is

A local agentic OS. Installs on your Windows machine, starts with blank memory, and stores memory on your machine as you use it.

  • Newborn seed — no seller’s personal bots, journals, or secrets
  • You bring your own API keys and pay your own model usage
  • Silence is not permission — Hydra proposes; sensitive actions need your say-so

What it is not

  • Not a cloud SaaS chatbot
  • Not a WhatsApp SOP kit for agencies or clinics
  • Not a clone of someone else’s lived-in Hydra with their history

Who it’s for

  • FOR

    Technical founders and power users who already use LLMs, want agents on their disk, and accept a real install + their own keys.

  • NOT

    Anyone who wants zero install, or a therapy / medical AI.

First hour

Real steps — not a demo script.

  1. Create a virtualenv and install requirements (pip install -r requirements.txt)
  2. Copy .env.example → .env and paste your key
  3. Run python main.py and open the UI (port 8765)
  4. Send one chat · open Boss / Jefe and see a local note

If you can’t do that in about an hour with the README, email support within the window below — don’t force a bad fit.
